# Convenções do projeto

## Pastas

- `src/` — HTML, CSS e JavaScript da interface.
- `assets/img/` — imagens otimizadas (JPG, PNG, SVG, WebP).
- `docs/` — combinados da turma e fluxos Git.

## Nomes

- Arquivos em minúsculas e hífen: `secao-contato.css`.
- Classes CSS em kebab-case: `.card-aluno`.
- Funções JS em camelCase: `atualizarAno()`.

## HTML

- Semântica (`header`, `main`, `section`, `footer`).
- Um `h1` por página.
- Textos em português.

## Git

- Branch principal: `main`.
- Feature: `feature/tema`.
- Correção: `fix/descricao`.
- Tag: `vMAJOR.MINOR.PATCH`.
